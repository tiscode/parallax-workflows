# Slide templates — Chicago Global / Parallax

Client-facing deck templates in the brand. Built on the `deck-stage.js` shell (keyboard nav, thumbnail
rail, print-to-PDF). Per `brand-guidelines.md` §16: Futura headlines, Gill Sans body, Optima numbers,
hard corners, navy + accent blue, **orange for one element per slide**, **no animations/transitions**,
and a *"Powered by Parallax"* footer on content slides.

## Run
Open `index.html`. Arrow keys / on-screen rail navigate. Print → Save as PDF for a clean one-page-per-slide export.

## Slide archetypes (edit text directly in the static markup)
1. **Title** — navy ground, CHICAGO GLOBAL wordmark, Futura headline, "Powered by Parallax".
2. **Coverage / stats** — three big Optima figures (62,000+ / 48 / 15+), one in orange.
3. **Six-Factor Framework** — 3×2 icon-card grid.
4. **Three Layers** — three-up with orange serif roman numerals (I / II / III).
5. **Positioning** — "We are / We are not" two-column comparison.
6. **Big quote** — cream ground, founder quote in Futura.
7. **Closing** — navy, contact + MAS licence + *"Solve the market."* tagline (orange italic, footer-only, Parallax).

## Notes
- Surface mode: title/closing use navy (allowed for title/cover); content slides are light per "when in doubt, light."
- Icons are inline Lucide via `../assets/icons-data.js` (substitute for the brand's 1.5px line set).
- The navy "beam" gradient is a stand-in for the real Chicago-Beam photograph (pending upload).
